# QuotaDuck website

Public product website and privacy policy for QuotaDuck, an independent Chrome extension for viewing ChatGPT Codex/Work and Claude usage allowances.

The extension source code remains in a separate private repository. This repository contains only the static website.

Website (after enabling GitHub Pages from `main` / `/(root)`): https://gaborgulyas.github.io/quotaduck-docs/

Privacy policy: https://gaborgulyas.github.io/quotaduck-docs/privacy.html

QuotaDuck is an independent project and is not affiliated with OpenAI or Anthropic.
